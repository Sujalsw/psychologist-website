## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `bun`

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Sujalsw/psychologist-website.git
   cd psychologist-website
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env` file in the root directory:
   ```env
   RESEND_API_KEY=your_resend_api_key_here
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:8080](http://localhost:8080) in your browser.

---

## ☁️ Deploying to Netlify

This project is pre-configured for seamless one-click deployment on **Netlify**:

1. Log in to [Netlify](https://app.netlify.com/) and click **Add new site** > **Import an existing project**.
2. Connect your GitHub account and select `Sujalsw/psychologist-website`.
3. Set Environment Variable under **Site Settings > Environment Variables**:
   - `RESEND_API_KEY`: *(Add your Resend API Key here)*
4. Click **Deploy Site**.

*Note: The included `netlify.toml` automatically handles building Vite and routing `/api/send-enquiry` to the Netlify Serverless Function!*
